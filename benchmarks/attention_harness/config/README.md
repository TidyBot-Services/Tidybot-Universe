# config/

`lobby-config.8769.json` is the demo lobby configuration proposed for the 8769 server (`--lobby-config`). It is the runtime
file `~/.config/attentionbench-8769/lobby-config.json` plus one source: `devexp-d9d6c17c…` (turn_on_microwave, seed 101,
4 attempts, 4 replay_trim sidecars). The running file is not edited from the repository; copy this one over it when 8769 is
restarted. Sources are recordings in the server's `daily-experiments` directory; `state_dir` must be an absolute path.
